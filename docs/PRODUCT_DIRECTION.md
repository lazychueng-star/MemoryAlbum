# 視覺方向：中古世紀魔法小屋

## 1. 北極星

使用者推開一扇位於魔法森林邊緣的舊木門，進入的不是普通相冊，而是一間有人住過、收藏著人生片段的中古世紀小屋。

核心感受：

- 溫暖、私密、好奇、可探索。
- 像手抄本插圖與實體工藝品，而不是遊戲 HUD。
- 魔法存在於光、材質、比例與小動態中；不要依賴滿屏發光符文。

一句話視覺定位：

> 月光下的古老木屋，壁爐、羊皮紙、銅器、苔蘚與被細心保存的記憶。

## 2. 色彩

建議建立 semantic tokens，不在 View 散落色值：

| Token | 用途 | 起始色 |
|---|---|---|
| `ink` | 主文字／深色背景 | `#171820` |
| `midnight` | 夜景基底 | `#20263A` |
| `parchment` | 紙張／卡片底 | `#E7D6B4` |
| `oak` | 木樑／書架 | `#5B3A27` |
| `moss` | 植物、布料點綴 | `#5D7055` |
| `brass` | 金屬框、標籤 | `#B28A4A` |
| `candle` | 暖光與主要強調 | `#F2A85B` |
| `moon` | 冷色月光、對比光 | `#9DB8D8` |
| `ember` | 危險、刪除、警示 | `#B95743` |

原則：

- 大面積以深木色、石灰牆與午夜藍為底，羊皮紙與暖光負責可讀性。
- 金屬只做小面積高光；不要讓所有物件都發光。
- 魔法色採克制的藍綠、琥珀或淡紫補光，避免霓虹紫藍漸層。
- 文字對比以 `parchment` + `ink` 或深底亮字為主，不把手寫字體用於正文。

## 3. 材質與建模語言

優先材質：

- 粗糙石灰牆、裂紋舊木、深色橡木樑、風化石、氧化黃銅。
- 羊皮紙、亞麻、羊毛、皮革、蜂蠟、玻璃瓶與書口紙張。
- 植物以乾燥香草、苔蘚、藤蔓為主，少量發光菌替代誇張魔法陣。

避免：

- 塑膠感 PBR、鏡面金屬滿屋、霓虹全息 UI。
- 現代極簡玻璃卡片直接浮在 3D 場景上。
- 通用手遊的厚金框、誇張技能按鈕、戰鬥 HUD。
- 過度高光泛白與密集粒子；會壓縮照片本身的視覺焦點。

3D 細節：

- 木屋比例可略歪斜，門框與屋頂不完全水平，呈現手工建造感。
- 每間房至少有一個大型輪廓辨識物：望遠鏡、藥材櫃、壁爐、巨書架。
- 拍立得與相框使用黃銅角、皮革扣、麻繩、蜂蠟封章。
- 魔法書寫與符文放低對比，主要作為近看細節。

## 4. 四個房間的初始方向

### 月相觀星閣

- 關鍵詞：舊天文儀、穹頂窗、月藍冷光、黃銅星盤、堆疊星圖。
- 照片展示：以可旋轉銅框與懸掛星圖呈現。

### 草藥與記憶藥房

- 關鍵詞：藥草束、玻璃瓶、抽屜上的手寫標籤、綠褐暖光。
- 照片展示：像藥材標本卡、抽屜內的小型相片卷。

### 古卷記憶畫廊

- 關鍵詞：拱形石廊、燭台、巨幅掛畫、舊書與卷軸。
- 照片展示：畫框、翻頁手抄本與壁龕。

### 爐火故事室

- 關鍵詞：壁爐、羊毛毯、皮椅、火光、窗邊雨夜。
- 照片展示：拍立得散落桌面、曬照片的麻繩與皮革相冊。

可沿用原本的「復古畫廊、雜貨鋪、觀測台、密室」功能定位，但外觀統一為中古世紀魔法小屋世界觀。

## 5. 字體與 UI 語言

- 標題可用有書卷感、襯線感的中文字體；正文保持高可讀。
- 英文小標可用小型大寫與字距，但不要全站濫用。
- 按鈕像黃銅銘牌、木牌或羊皮紙標籤；仍需保留明確 hit area。
- 導航標籤避免「遊戲技能欄」；優先像屋內物件或手寫索引。
- 手寫字體只用於便簽、日期與短標籤，不用於 EXIF 或功能說明。

## 6. 動態原則

主要動態：

- 選屋：緩慢推近、輕微視差、門縫暖光。
- 室內：燭火呼吸、布料與懸掛物微動、紙張邊角輕顫。
- 相片翻面：先抬離桌面，再繞 Y 軸翻轉，完成後有少量灰塵或紙張回彈。
- 進出展廳：相機像走進空間，不做全屏萬花筒特效。

運動參數起點：

- 主要鏡頭：0.55–0.9 秒，ease-in-out 或平滑 spring。
- 卡片翻面：0.45–0.65 秒，damping 高，避免卡通彈跳。
- 視差：限制在 4–12 pt；不要讓大場景追隨手指過度晃動。
- 粒子：以運鏡與光線建立魔法感，粒子數量和覆蓋率保持克制。

Reduce Motion：

- 停用視差、粒子視差、長距離鏡頭移動。
- 翻面改為短淡入切換，但仍保留正反面資訊。

## 7. 照片展示語言

照片必須是場景主角。建議樣式：

- `hearthPolaroid`：奶油白邊、手寫日期、輕微紙張彎曲陰影。
- `brassFrame`：黃銅細框、深色木背板。
- `apothecaryCard`：亞麻布標本卡、麻繩與小蠟封。
- `openFolio`：左右頁手抄本，左頁照片、右頁手寫記憶。
- `omensChest`：木抽屜，拉開後看到多張相片。

背面資訊：

- EXIF 以「保管者手記」形式呈現，但仍使用清楚表格／可讀字體。
- 光圈、快門、鏡頭、日期可像舊式檔案卡片的分欄。
- 私密便簽使用皮革內頁或摺疊羊皮紙，不用現代玻璃面板。

## 8. 不要在風格化時犧牲可用性

- 所有物件即使沒有魔法光也必須看得懂。
- 文字不能依賴背景紋理；需有不透明度足夠的底層。
- 最少的觸控目標 44×44 pt。
- VoiceOver 讀出「房間、照片張數、選中狀態」，不讀裝飾紋理。
- Dynamic Type、對比、Reduce Motion 與色盲辨識皆為驗收項。
- 風格一致性不能成為導入未授權字體、材質或 3D 模型的理由。

## 9. 驗收畫面

第一輪視覺 spike 至少產出：

1. 首頁：夜間森林邊緣的四座魔法小屋。
2. 爐火故事室：桌面拍立得與暖光。
3. 月相觀星閣：RealityKit 房內視角與一張 3D 相片。
4. 拍立得正面與 EXIF 背面。

若畫面拿掉發光效果後仍然像一間可信、溫暖、可居住的魔法小屋，方向即為成功。
